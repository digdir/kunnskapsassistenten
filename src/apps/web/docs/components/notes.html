Notes

DraftOptionalTools

Lets the user collect excerpts from sources in their own notes, keeping the footnote and source list.

UI name
«Notater», buttons say «Mine notater»
Sits in
The tools panel
Issue
#181
Canvas
00-Notater (NO-A1, NO-A2, NO-B1, NO-C1), KS-2e

Use it when

  • Users will reuse answers and excerpts in their own writing.

Variants

  • Bring in excerpts (NO-A1), finished note (NO-A2), write with source check (NO-B1), export (NO-C1).

Related

  • Sources: excerpts are brought in from a source
  • Footnotes: notes keep the footnote and source list

What we have learned

  • Notes must not compete with the answer: a weaker surface, and hidden while empty.
  • Call it «Notater», with buttons saying «Mine notater». Not «Arbeidsflate».
  • Call it «Hent inn», not «Kopier». The excerpt brings its source along.
  • The export button says «Eksporter med kilder».
