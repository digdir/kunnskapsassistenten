Sources

DraftOptionalTools

Shows the documents and excerpts behind an answer, with how relevant each source is.

UI name
«Kilder»
Sits in
The tools panel, and as a section after the answer
Issue
#177
Canvas
00-Kilder (KI-A1 to KI-C1)

Use it when

  • Users should be able to see and judge what the answer is based on.

Variants

  • A, three panels: sources in the tools panel next to the answer.
  • B, order and source colour: the order of the sources, and a colour per source.
  • C, own sources (KI-C1): sources the user has kept.
  • Sources used in the answer: a section after the answer, a neutral surface with white cards.

Related

  • Footnotes: a footnote opens the matching source
  • Document view: a source opens the document
  • Notes: excerpts can be brought into notes
  • Filter: decides which documents can become sources
