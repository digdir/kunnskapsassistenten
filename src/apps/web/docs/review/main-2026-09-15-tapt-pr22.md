# PR #22 er merget, men innholdet er ikke på `main`

2026-09-15, anmelderen (KA CC). Funnet mens jeg skrev regresjonstestene for
brukerblikk-funnene.

**Seks brukerblikk-rettelser i navigasjonspanelet er borte fra `main`.** PR #22
står som `MERGED` hos GitHub (`mergedAt: 2026-09-15T09:50:24Z`), og
merge-commiten `db0d341` finnes — men den er ikke forelder til `main`.

## Bevis

`FacetField.tsx` på `main` i dag:

```js
const state = chosen === 0 || allChosen ? 'Alle valgt' : `${chosen} av ${total} valgt`;
```

Det er koden fra **før** funn 3: null valgt og alt valgt sier ordrett det
samme. På `feat/primary-sidebar-brukerblikk` står tre tilstander med «Ingen
avgrensning» og «Alle N valgt».

Alle fem filene PR-en rørte er ulike på `main`:

```
src/views/filters/FacetField.tsx       ULIKT
src/views/filters/DocumentsList.tsx    ULIKT
src/views/filters/filters.css          ULIKT
```

Og endringen finnes ingen steder i historikken til `main`:

```
$ git log --all -S "Ingen avgrensning" -- src/views/filters/FacetField.tsx
9c09397  refs/heads/feat/primary-sidebar-brukerblikk
```

Bare på branchen. Aldri inn.

## Hvor den ble borte

```
$ git cat-file -p 9c5db86          # «Slår sammen main etter #19, #22 og #32»
parent 72229db   (#33 sin head)
parent 9cb733f   (#32 sin merge)
```

Ingen av de to foreldrene inneholder #22. Merge-commiten `db0d341` som GitHub
lagde for #22 er altså ikke med i grafen `9c5db86` bygger på — den ble
skrevet over.

De andre er i orden. Innholdssjekket: #19, #24, #25, #26, #30, #31, #32 og #33
er alle på `main`. **#22 er den eneste som mangler.**

## Hvorfor ingenting fanget det

PR #22 endret også min `primary-sidebar.spec.ts` — påstanden som låste funn 3
på den nye ordlyden. Den endringen forsvant i samme slengen. Så testen på
`main` sjekker fortsatt den gamle ordlyden, mot den gamle koden, og er grønn.

Koden og testen som ville felt den gikk tapt sammen. Det er verdt å merke seg:
en suite kan ikke oppdage at den selv ble rullet tilbake.

## Gjenoppretting

```sh
git checkout main
git merge origin/feat/primary-sidebar-brukerblikk
```

Branchen står, `9c09397` er intakt, og den merger rent mot `main` — jeg
prøvde. De sju testene i `tests/e2e/brukerblikk.spec.ts` går fra fem røde til
alle grønne i det den er inne, så gjenopprettingen kan verifiseres uten å lese
koden.

## Hva jeg har gjort

`tests/e2e/brukerblikk.spec.ts` er ny, sju tester som holder funn 3, 8, 9, 10,
12, 13 og 16. Verifisert: **alle sju grønne** mot
`feat/primary-sidebar-brukerblikk` slått sammen med `main`; **fem røde** mot
`main` alene, og de fem er nøyaktig de #22 skulle levert.
