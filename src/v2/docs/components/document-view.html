Document view

DraftOptionalTools

Shows the whole document from a source, with the excerpt marked, and lets the user ask questions about the document.

UI name
«Dokumentvisning»
Sits in
The tools panel
Issue
#182
Canvas
00-Dokumentvisning (FN-1b, FN-1c, FN-1d), KA-3b

Use it when

  • Users need to read a source in context, not just the excerpt.

Variants

  • The source opened at the PDF page, with the passage highlighted.
  • Ask in the document, and send the question back to the thread.

Related

  • Sources and Footnotes: open the document
  • Chat: a question asked in the document goes back to the thread

What we have learned

  • Users need to see the passage and the sources behind a claim, and make their own judgement.
  • Users should be able to move between the excerpts in a document.
