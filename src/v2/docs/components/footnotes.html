Use it when

  • Users must be able to check each claim against its source.

Variants

  • With the sources panel open and closed. Footnotes must work in both.

Related

  • Sources: a footnote opens the matching source
  • Document view: a footnote can open the document at the excerpt

What we have learned

  • The source list at the bottom is in the same order as the footnotes. One quote per place a source is used.
