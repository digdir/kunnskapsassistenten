Use it when

  • Users work on a case over time, with the same documents and instructions across several threads.

Variants

  • Overview, new project, the project, a thread in a project, and moving a thread (PR-1 to PR-5).
  • Adding sources: choose below the filter (PR-3c2) or search above it (PR-3c3). Both are being considered.

Related

  • Threads: grouped under a project
  • Filter: a project's documents are added with the filter

What we have learned

  • The project owns the instructions, the fixed documents and the threads.
  • A thread owns its own document selection: the project's fixed documents, plus what is added in the thread.
  • The project's instructions win over «Om deg» when they disagree.
  • A thread moved into a project gets the project's instructions and documents from the next question. Earlier answers don't change.
  • Hypothesis: the filter is still needed when starting a thread in a project. Test: do users change the selection when they start new threads, and what do they put at project level?

Open questions

  • Does a project need its own starting point in Kudos, or are fixed documents enough?
  • Can a fixed project document be removed from one thread?
  • Sharing and access in projects haven't been thought through yet.
